# Sistema de iconografía

Los iconos se sirven como SVG locales para evitar dependencias de CDN y mantener
la interfaz rápida, consistente y disponible sin conexión.

- `technologies/`: marcas tecnológicas obtenidas de Simple Icons.
- `brands/`: redes sociales y canales con identidad visual propia.
- `functional/`: acciones y conceptos generales obtenidos de Lucide.

Las marcas conservan su color oficial cuando mejora su reconocimiento. Los
conceptos sin logotipo oficial utilizan un icono funcional; no se crean marcas
ficticias. La navegación permanece únicamente con texto para evitar ruido visual.

Fuentes:

- Simple Icons: https://simpleicons.org/ (CC0 1.0)
- Lucide: https://lucide.dev/ (ISC)

Las asociaciones, colores y agrupaciones se administran en
`config/iconography.yml`.
